ОПИСАНИЕ
AVE Addon Manager помогает настроить видимость существующих вкладок аддонов в боковой панели N в 3D Viewport. Условия можно задавать для рабочих пространств Blender (верхние вкладки) и режимов Object / Edit. Он не перемещает аддоны и не предназначен для изменения их собственных настроек.

ОСНОВНЫЕ ВОЗМОЖНОСТИ
• Список включённых аддонов, у которых обнаружены панели в N-sidebar; поиск и «Избранное» (звёздочка) для фильтрации списка.
• Раскрывающаяся карточка аддона: найденные вкладки N-панели, режим отображения и перечень текущих рабочих пространств Blender с галочками.
• Use original addon behavior: исходное поведение выбранного аддона; включено по умолчанию.
• Правила Object / Edit и отдельных рабочих пространств применяются только при включённых соответствующих фильтрах и после Apply rules for this session.
• При открытии Blender менеджер стартует без активных ограничений. Настройка отображения действует в текущем сеансе после явного запуска.
• Restore panels — попытка вернуть исходную регистрацию и логику отображения панелей.
• Original snapshot — JSON-снимок сведений о найденных N-панелях и данных AVE, НЕ полная копия предпочтений сторонних аддонов.
• Export JSON / Import JSON — перенос правил AVE, избранного и назначений; имя файла экспорта по умолчанию AVE_Addons.json. Импорт не устанавливает отсутствующие аддоны и не включает импортированные ограничения автоматически.
• Force synchronize — ручная попытка синхронизации при конфликте; использовать осторожно, после резервного копирования.
• Переключение языка RU/EN: Edit → Preferences → Add-ons → AVE Addon Manager.
• Ссылка на автора: https://boosty.to/ave_blender.

УСТАНОВКА
1. Blender 5.2 LTS: Edit → Preferences → Add-ons → Install from Disk.
2. Укажите ZIP без распаковки и включите AVE Addon Manager.
3. Откройте 3D Viewport → N → AVE Addons.
4. При первом запуске согласитесь на создание исходного снимка, если хотите иметь копию сведений AVE.
5. Настройте нужные аддоны: снимите Use original addon behavior, задайте рабочие пространства и/или режим, включите нужный фильтр, нажмите Apply rules for this session.
6. Проверяйте по одному аддону, затем сохраните настройки Blender при необходимости.

ВОССТАНОВЛЕНИЕ И УДАЛЕНИЕ
Перед удалением желательно нажать Restore panels. При штатном отключении AVE пытается откатить временные изменения. Если сторонняя вкладка не появилась, полностью перезапустите Blender, а при необходимости отключите и вновь включите проблемный аддон. Абсолютная совместимость с любыми сторонними аддонами не гарантируется.

ДАННЫЕ И ОГРАНИЧЕНИЯ
AVE не должен изменять исходные .py-файлы других аддонов. Для временной фильтрации он вмешивается в регистрацию/условия отображения некоторых Python-панелей Blender в памяти текущего сеанса, поэтому возможны несовместимости. Снимок JSON не заменяет резервную копию пользовательского каталога Blender.
