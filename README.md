# AVE Addon Manager

**A free Blender add-on for organizing your N-panel.**

**Version:** 0.8.0 Alpha  
**Blender:** 5.2 LTS  
**Languages:** English / Russian  
**Status:** Public Alpha — testing

## What is it?

AVE Addon Manager is a small utility that helps you organize Blender's N-panel without constantly enabling and disabling add-ons.

You can choose which add-on panels appear in different Blender workspaces and modes while keeping the add-ons themselves enabled.

## Features

- **Workspace-based visibility** — customize which add-on panels appear in Layout, Modeling, Rigging, or your own workspaces.
- **Object/Edit Mode filtering** — control panel visibility depending on the current mode.
- **Original add-on behavior** — preserve an add-on's own visibility rules.
- **Favorites** — quickly find frequently used add-ons.
- **JSON import/export** — back up and share your AVE configurations.
- **RU/EN interface** — switch languages in the add-on preferences.
- **Panel restoration** — restore original panel behavior when disabling AVE.

## Installation

1. Download the ZIP file from the [Releases](https://github.com/AveKven/AVE-Addon-Manager/releases) page.
2. Open Blender 5.2.
3. Go to **Edit → Preferences → Add-ons → Install from Disk**.
4. Select the ZIP file without extracting it.
5. Enable **AVE Addon Manager**.
6. Open the 3D Viewport sidebar using `N` and select **AVE Addons**.

## Important — Alpha Version

This is an experimental release. Bugs and compatibility issues are possible.

Before testing, back up your Blender preferences.

AVE Addon Manager does not modify other add-ons' source files. Its visibility rules are applied manually, and it attempts to restore the original panels when disabled.

Compatibility with every third-party add-on is not guaranteed.
